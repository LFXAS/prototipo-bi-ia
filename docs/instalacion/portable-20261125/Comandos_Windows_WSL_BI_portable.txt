PAQUETE NUEVO AUN PENDIENTE DE CONSTRUIR Y VERIFICAR.
Este TXT es documentacion, NO un script. No ejecutarlo con bash, sh o PowerShell -File.
Leer primero el PDF. Ejecutar UNA orden cada vez y verificar el resultado.
Los comandos read solicitan nombres reales observados. No escribir el indicador $ de la terminal.
No se incluyen contrasenas ni API keys. Ninguna orden de instalacion se ejecuto al crear esta guia.

USO: primera instalacion Windows. Se indica si cada orden va en PowerShell o en Ubuntu/WSL.
NO incluye retiradas del BI de Lenovo. No adaptar sus guardas a otro equipo.
Las ordenes 04, 05 y 07 son alternativas condicionadas, NO una secuencia obligatoria.
