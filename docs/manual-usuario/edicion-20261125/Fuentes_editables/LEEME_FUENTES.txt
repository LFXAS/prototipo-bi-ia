EDITAR Y COMPILAR
1. Fuente principal: manual_latex/main.tex. Capítulos: manual_latex/secciones/.
2. Recursos relativos: manual_latex/recursos/. Mantener el conjunto unido.
3. Las fuentes TeX Gyre están incluidas, con licencia GUST, en recursos/fuentes/.
4. Para compilar con TeX Live completo y XeLaTeX, desde manual_latex ejecute:

   latexmk -xelatex -interaction=nonstopmode -halt-on-error main.tex

   O ejecute xelatex dos veces. No se necesita la aplicación ni una API key.
5. El resultado de compilación es main.pdf; el PDF con nombre de entrega es una
   copia de ese resultado final, comprobada por SHA-256.
